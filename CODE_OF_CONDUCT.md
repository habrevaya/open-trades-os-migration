# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space it runs: issues, pull requests,
discussions and anywhere else the project is represented.

The short version: be considerate, assume good faith, criticise the work and
not the person, and remember that a lot of the people here run small
businesses and are giving up time they would otherwise be billing.

## Reporting

Report anything that breaks it privately to the maintainer,
[@habrevaya](https://github.com/habrevaya), through the contact details on
that GitHub profile. Reports are kept confidential. The maintainer decides
the response, following the Covenant's enforcement guidelines, from a
warning up to a permanent ban.
